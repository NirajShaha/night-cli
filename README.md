#NightCli

1. create package.json
2. bun create opentui --template react, create a project name.
3. inside project remove bun.lock file, README.md and .gitignore.
4. make changes in project-name/package.json and tsconfig.json
5. create and make changes in root/tsconfig.base.json.
6. in the root run bun install, to sync.
